# Raya Lukia — Edição dos jogadores

Abra esta pasta como um cofre no Obsidian e comece por [[Comece aqui]].

Para uma leitura direta, abra `Eventos - leitura.html` no navegador. A página inclui todos os relatos e botões para copiar as mensagens de WhatsApp e Discord.

Os relatos também estão em Markdown na pasta `Eventos`. Cada arquivo de texto em `Compartilhar` corresponde a uma mensagem pronta para copiar. As partes numeradas devem ser enviadas na ordem.

# Biblioteca azul

O grupo acessa este espaço por uma passagem na biblioteca comum. O corredor de entrada é feito de pedra rúnica.

A biblioteca azul parece construída de mana, com paredes que se perdem no alto e superfícies lisas como vidro. O piso produz sons a cada passo. Entre as estantes, há cheiro de rosas, roupa limpa e fumaça.

Foi ali que os quatro encontraram [[Renné]]. Durante o confronto, as estantes se afastaram e abriram uma arena. Renné apontou uma porta para outros espaços de confinamento. Ao tentarem ajudá-la, os alunos foram expulsos de volta à biblioteca.
